# Contributing

Describe device model, BB10 version, BerryCore version, toolkit revision, reproduction steps, observed behavior and expected behavior. Remove credentials and private conversation text from reports.

Keep upstream attribution and per-file licenses. Do not bundle SDKs, model weights or runtime libraries without checking their redistribution requirements. Separate source changes from downloaded dependencies. Run docs/TESTING.md for changed modules and identify tests that require hardware.

Record host tests, device programmatic checks and physical keyboard/touchscreen acceptance separately. Do not generalize one Classic result to all BB10 devices. Back up existing working installations before any device experiment. Pi's confirmation hooks are not an OS sandbox.
